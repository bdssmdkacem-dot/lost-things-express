# Game Design — The Lost Things Express

## Design pillars
1. **Curiosity:** every lost object hints at a larger story.
2. **Play first:** objects are tools, clues, or mechanisms—not just collectibles shown in cutscenes.
3. **Cozy mystery:** wonder and gentle tension, never arbitrary punishment.
4. **Consequences:** choices change keepsakes, compartments, routes, and story fragments.
5. **Mobile clarity:** short sessions, readable UI, forgiving controls, and quick resume.
6. **Premium presentation:** cinematic lighting, expressive animation, carefully composed scenes, and memorable audio.

## Core loop
Explore carriage → notice an object → inspect and connect clues → solve an environmental puzzle → restore or use the object → reveal a memory → unlock a new route.

## Vertical slice: “The Station That Forgot Its Name”
- Setting: one antique train carriage arriving at an unlisted station.
- Key props: brass key, torn letter, memory chest.
- Puzzle: discover the key, inspect the letter, infer the clue, unlock the chest.
- Reward: an old photograph revealing the next destination.
- End: a short cinematic transition and a clear continue prompt.

## Commercial readiness requirements
Before a public release, the game needs:
- Save/load and safe resume after app suspension.
- Pause menu and settings for audio, look sensitivity, text size, and reduced motion.
- Subtitles for spoken story moments.
- Clear feedback for interactable objects and puzzle state.
- Error handling for interrupted scenes and invalid save data.
- Device performance budgets and repeatable QA.
- No forced ads during the opening experience. Monetization decisions follow evidence of player enjoyment.
- Privacy and consent review before analytics or any account-based service.
